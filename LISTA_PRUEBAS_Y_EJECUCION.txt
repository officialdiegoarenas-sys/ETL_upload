DASHBOARD DE ENTIDADES DE CONTROL
Abrir la carpeta del proyecto en Visual Studio Code (File > Open Folder) y
luego Terminal > New Terminal. La carpeta debe contener iniciar_dashboard.bat.
---------------------------------------------------------------------

CODIGO 1: INSTALAR (solo la primera vez, tarda unos 3 minutos)

    python -m venv .venv
    .\.venv\Scripts\python.exe -m pip install -r requirements.txt


CODIGO 2: EJECUTAR Y VER EL DASHBOARD

    .\iniciar_dashboard.bat

    Se abre en http://localhost:8501
    Ingreso: un correo con "fiscalia" (ej. diegofiscalia@gmail.com) y cualquier contrasena.
    Se abre una ventana negra (la API): dejarla abierta.
